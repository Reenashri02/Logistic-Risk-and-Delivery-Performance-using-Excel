# Logistics Risk and Delivery Performance Analysis

## 📌 Project Overview

This project analyzes logistics and delivery data to understand **delivery performance, delays, carrier performance, shipping costs, and delivery risk**.

The analysis was performed using **Microsoft Excel** with formulas, business questions, and dashboards to identify important logistics patterns and support better operational decision-making.

## 🎯 Project Objective

The main objective is to analyze delivery operations and identify:

* On-time and delayed deliveries
* Delivery performance by carrier and region
* Shipping cost and order value patterns
* High-risk shipments
* Delay-related trends
* Factors affecting logistics performance

## 📂 Dataset

**File:** `Logistics Risk and Delivery Performance using Excel.xlsx`

The dataset contains **1,000 logistics records** and **17 columns**.

### Important Columns

| Column                 | Description                    |
| ---------------------- | ------------------------------ |
| Order ID               | Unique order identifier        |
| Order Date             | Date when the order was placed |
| Delivery Date          | Actual delivery date           |
| Customer               | Customer identifier            |
| Region                 | Delivery region                |
| Product Category       | Category of the product        |
| Carrier                | Logistics/shipping company     |
| Shipping Mode          | Type of shipping service       |
| Distance (km)          | Delivery distance              |
| Shipping Cost          | Cost of shipping               |
| Order Value            | Value of the order             |
| Expected Delivery Days | Expected delivery duration     |
| Actual Delivery Days   | Actual delivery duration       |
| Delay Days             | Number of delayed days         |
| Delivery Status        | On Time / Delayed              |
| Risk Score             | Calculated delivery risk score |
| Risk Level             | Low / Medium / High            |

## 📊 Business Questions

Some of the key questions addressed in this project are:

1. What is the total number of orders?
2. How many orders were delivered on time?
3. How many orders were delayed?
4. Which carrier handles the most orders?
5. Which carrier has better delivery performance?
6. Which region has the highest number of delays?
7. Which shipping mode is used most frequently?
8. What is the total shipping cost?
9. What is the total order value?
10. Which product category has the highest order value?
11. Which carrier has the highest shipping cost?
12. How many orders require immediate attention based on risk?
13. Which region has the highest-risk shipments?
14. What is the relationship between delay days and risk level?
15. Which areas require improvement in logistics performance?
